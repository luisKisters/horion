One overlap rule, combined

Left: how the app lays out the day now. Right: the new rule. Same events, real size.

  1. Longer goes behind. A long event is the background; events that start later sit on top of it, one small step in. Busy days no longer switch to thin columns.
  2. No title is drawn over. If sitting on top would cover another event's title (they start less than 22 min apart), it goes beside it instead.
  3. Much shorter tucks in. Something at most half as long as the event it starts with (a task, a quick call) sits on that event's right half. The long one keeps its full width.
  4. Similar lengths share. Events of similar length that start together split the width equally, longest on the left.
  5. Never too thin. If sharing would make a title too narrow to read, the group takes some of the indent instead (the background's colour bar stays). Only four or more titles in one line can't all fit.
